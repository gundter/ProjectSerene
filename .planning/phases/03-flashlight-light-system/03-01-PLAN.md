  <action>
Create UFlashlightComponent ActorComponent following the SanityPerceptionComponent pattern.

**Header (FlashlightComponent.h):**
- Include guards and forward declarations (USpotLightComponent, UGameplayEffect, USoundBase)
- EFlashlightState enum: Off, On (keep simple for this plan - WarmingUp, Flickering, DyingOut in Plan 02)
- UPROPERTY for SpotLight reference (set by HorrorCharacter after construction)
- UPROPERTY EditDefaultsOnly for:
  - TSubclassOf<UGameplayEffect> BatteryDrainEffect
  - USoundBase* ToggleOnSound
  - USoundBase* ToggleOffSound
  - float BaseIntensity = 5000.0f (lumens)
- FActiveGameplayEffectHandle for drain effect
- Private: CurrentState, cached ASC
- Public methods:
  - void Initialize(USpotLightComponent* InSpotLight) - called by HorrorCharacter
  - void Toggle() - main toggle function
  - bool IsOn() const
  - EFlashlightState GetState() const

**Implementation (FlashlightComponent.cpp):**
- Constructor: Initialize defaults
- BeginPlay: Cache owner ASC, bind to Battery attribute changes
- EndPlay: Clean up drain effect, unbind delegates
- Toggle():
  - If Off and Battery > 0: TransitionToState(On)
  - If On: TransitionToState(Off)
  - Play appropriate toggle sound via UGameplayStatics::PlaySoundAtLocation
- TransitionToState(EFlashlightState NewState):
  - Exit current state (stop drain if On)
  - Set CurrentState = NewState
  - Enter new state (start drain if On, set light visibility)
  - Add/remove State.FlashlightOn tag
- StartBatteryDrain(): Apply BatteryDrainEffect (same pattern as HorrorCharacter stamina drain)
- StopBatteryDrain(): Remove effect via handle
- OnBatteryChanged(const FOnAttributeChangeData& Data):
  - If Battery <= 0 and state is On: TransitionToState(Off)
  - (Flicker threshold will be added in Plan 02)
- SetLightEnabled(bool bEnabled): SpotLight->SetVisibility(bEnabled)
- GetOwnerASC(): Same pattern as SanityPerceptionComponent::GetOwnerASC

**Add State.FlashlightOn tag to SereneGameplayTags.h/cpp:**
- Add declaration: UE_DECLARE_GAMEPLAY_TAG_EXTERN(State_FlashlightOn);
- Add definition: UE_DEFINE_GAMEPLAY_TAG(State_FlashlightOn, "State.FlashlightOn");
- Add comment in header documenting purpose

Follow established code style:
- Copyright header
- Include guards
- Detailed doc comments
- UPROPERTY metadata (EditDefaultsOnly, Category, meta)
- Consistent use of validity checks (if (!SpotLight) return)

Document the Blueprint configuration steps required in Unreal Editor. This will be included in the SUMMARY.md for the user to complete after C++ execution.

**IA_ToggleFlashlight Input Action:**
1. Create new Input Action asset in Content/Variant_Horror/Input/
2. Name: IA_ToggleFlashlight
3. Value Type: Digital (Bool)
4. No triggers needed (default press)

**IMC_Horror Input Mapping Context:**
1. Open existing IMC_Horror (or create if missing)
2. Add mapping: IA_ToggleFlashlight -> Keyboard F

**GE_BatteryDrain Gameplay Effect:**
1. Create in Content/Variant_Horror/Blueprints/Gameplay/GameplayEffects/
2. Duration Policy: Infinite
3. Period: 0.5 seconds
4. Modifiers:
   - Attribute: SereneAttributeSet.Battery
   - Modifier Op: Add
   - Magnitude Type: Scalable Float
   - Magnitude Value: -1.67 (drains ~3.33/sec = 30 seconds from 100 to 0)

Note: 30 seconds is conservative; can tune later. Research suggested 60s but deferring to user preference.

**BP_HorrorCharacter Configuration:**
1. Open BP_HorrorCharacter
2. Select FlashlightComponent in Components panel
3. Set Battery Drain Effect: GE_BatteryDrain
4. Optionally set ToggleOnSound and ToggleOffSound (mechanical click)
5. Select HorrorCharacter (self) in Details
6. Set Toggle Flashlight Action: IA_ToggleFlashlight

**Verification steps:**
1. Play in Editor
2. Press F - flashlight should turn on, illuminate scene
3. Battery HUD should start decreasing
4. Press F again - flashlight should turn off
5. Wait for battery to deplete - flashlight should auto-off
