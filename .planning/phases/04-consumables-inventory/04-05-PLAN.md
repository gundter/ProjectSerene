# Consumable Gameplay Effects Setup

Documentation for creating instant Gameplay Effects used by consumable items.
All effects use Duration Policy: Instant with Additive modifier.

## Effects to Create

Location: Content/Variant_Horror/Blueprints/Gameplay/GameplayEffects/

### GE_RestoreBattery (Full Restore)

**Purpose:** Restore flashlight battery to 100%

1. Right-click > Blueprint Class > GameplayEffect
2. Name: `GE_RestoreBattery`
3. Configure:
   - **Duration Policy:** Instant
   - **Modifiers:**
     - Attribute: `SereneAttributeSet.Battery`
     - Modifier Op: `Override` (set to max)
     - Modifier Magnitude > Magnitude Calculation Type: `Scalable Float`
     - Scalable Float Magnitude: `100`

Alternative using Add: Use Magnitude `100` with `Add` op, clamping handles overflow.

### GE_RestoreHealth_Small (Bandage +30)

**Purpose:** Restore 30 health (bandage)

1. Right-click > Blueprint Class > GameplayEffect
2. Name: `GE_RestoreHealth_Small`
3. Configure:
   - **Duration Policy:** Instant
   - **Modifiers:**
     - Attribute: `SereneAttributeSet.Health`
     - Modifier Op: `Add`
     - Scalable Float Magnitude: `30`

### GE_RestoreHealth_Large (Med Kit +75)

**Purpose:** Restore 75 health (med kit)

1. Right-click > Blueprint Class > GameplayEffect
2. Name: `GE_RestoreHealth_Large`
3. Configure:
   - **Duration Policy:** Instant
   - **Modifiers:**
     - Attribute: `SereneAttributeSet.Health`
     - Modifier Op: `Add`
     - Scalable Float Magnitude: `75`

### GE_RestoreStamina (Energy Drink +50)

**Purpose:** Restore 50 stamina (energy drink)

Per RESEARCH.md recommendation: Start with 50% (50 stamina), same pattern as mild medication.

1. Right-click > Blueprint Class > GameplayEffect

3. Configure:
   - **Duration Policy:** Instant
   - **Modifiers:**
     - Attribute: `SereneAttributeSet.Stamina`

     - Scalable Float Magnitude: `50`

### GE_RestoreSanity_Mild (Mild Medication +30)

**Purpose:** Restore 30 sanity (mild medication)

1. Right-click > Blueprint Class > GameplayEffect
2. Name: `GE_RestoreSanity_Mild`
3. Configure:
   - **Duration Policy:** Instant
   - **Modifiers:**
     - Attribute: `SereneAttributeSet.Sanity`
     - Modifier Op: `Add`
     - Scalable Float Magnitude: `30`

Note: This can push sanity past the 80% regen cap since it's not regen.

### GE_RestoreSanity_Full (Strong Medication Full Restore)

     - Modifier Op: `Override`

## Verification

After creating all effects:

1. Open ShowDebug AbilitySystem in PIE
2. Apply each effect via console: `ApplyGE GE_RestoreBattery`
3. Verify attribute changes to expected values
4. Check that existing UI updates (HorrorUI attribute delegates)

## Notes

- All effects are Instant - they modify and complete immediately
- Clamping to MaxAttribute is handled by SereneAttributeSet::PostGameplayEffectExecute
- Override op sets exact value; Add op is additive and clamped
- These effects are referenced by ItemDataAsset::UseEffect property
