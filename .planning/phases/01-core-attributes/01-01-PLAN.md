<task type="auto">
  <name>Task 2: Create SereneAttributeSet with All Attributes</name>
  <files>
    Source/ProjectSerene/GAS/SereneAttributeSet.h
    Source/ProjectSerene/GAS/SereneAttributeSet.cpp
  </files>
  <action>
Create `SereneAttributeSet.h`:

1. Include guards and includes:
   - "CoreMinimal.h"
   - "AttributeSet.h"
   - "AbilitySystemComponent.h"

2. Define ATTRIBUTE_ACCESSORS macro (standard GAS pattern):
   ```cpp
   #define ATTRIBUTE_ACCESSORS(ClassName, PropertyName) \
       GAMEPLAYATTRIBUTE_PROPERTY_GETTER(ClassName, PropertyName) \
       GAMEPLAYATTRIBUTE_VALUE_GETTER(PropertyName) \
       GAMEPLAYATTRIBUTE_VALUE_SETTER(PropertyName) \
       GAMEPLAYATTRIBUTE_VALUE_INITTER(PropertyName)
   ```

3. Create USereneAttributeSet class inheriting UAttributeSet with:
   - UPROPERTY BlueprintReadOnly for each attribute
   - 8 FGameplayAttributeData members:
     - Health, MaxHealth
     - Stamina, MaxStamina
     - Sanity, MaxSanity
     - Battery, MaxBattery
   - ATTRIBUTE_ACCESSORS for each attribute
   - Override PreAttributeChange for clamping CurrentValue
   - Override PostGameplayEffectExecute for clamping BaseValue and applying state tags

Create `SereneAttributeSet.cpp`:

1. Constructor: Initialize all attributes to 0 (actual values set via Gameplay Effect)

2. PreAttributeChange implementation:
   - Clamp Health to [0, MaxHealth]
   - Clamp Stamina to [0, MaxStamina]
   - Clamp Sanity to [0, MaxSanity]
   - Clamp Battery to [0, MaxBattery]
   - Note: Per CONTEXT.md, attributes CAN overfill above 100 temporarily, so clamp to MaxValue not 100

3. PostGameplayEffectExecute implementation:
   - Same clamping for BaseValue after instant effects
   - Apply/remove state tags based on thresholds:
     - Health <= 30% of MaxHealth: add State.LowHealth
     - Stamina <= 20% of MaxStamina: add State.LowStamina
     - Sanity <= 30% of MaxSanity: add State.LowSanity
     - Battery <= 20% of MaxBattery: add State.LowBattery
     - Health == 0: add State.Dead
  </action>
  <verify>
    File exists and contains:
    - All 8 attribute definitions
    - ATTRIBUTE_ACCESSORS for each
    - PreAttributeChange override
    - PostGameplayEffectExecute override
  </verify>
  <done>AttributeSet defines Health, Stamina, Sanity, Battery (with Max variants), with proper clamping</done>
</task>
