Create USanityPerceptionComponent (UActorComponent subclass):

**Header (SanityPerceptionComponent.h):**
```cpp
UCLASS(ClassGroup=(Horror), meta=(BlueprintSpawnableComponent))
class PROJECTSERENE_API USanityPerceptionComponent : public UActorComponent
{
    GENERATED_BODY()

public:
    USanityPerceptionComponent();

protected:
    virtual void BeginPlay() override;
    virtual void EndPlay(EEndPlayReason::Type EndPlayReason) override;

    // ----------------------------------------
    // Light Detection Configuration
    // ----------------------------------------

    /** Radius for light detection (cm) - approximately 5-6 meters */
    UPROPERTY(EditDefaultsOnly, Category = "Light Detection")
    float LightDetectionRadius = 550.0f;

    /** Grace period before drain starts after leaving light (seconds) */
    UPROPERTY(EditDefaultsOnly, Category = "Light Detection")
    float GracePeriodDuration = 1.5f;

    /** Interval for light proximity checks (seconds) */
    UPROPERTY(EditDefaultsOnly, Category = "Light Detection")
    float LightCheckInterval = 0.1f;

    /** Tag that marks a light as flickering (no protection) */
    UPROPERTY(EditDefaultsOnly, Category = "Light Detection")
    FName FlickeringLightTag = FName("FlickeringLight");

    /** Tag that marks any actor as a protective light source */
    UPROPERTY(EditDefaultsOnly, Category = "Light Detection")
    FName ProtectiveLightTag = FName("ProtectiveLight");

    // ----------------------------------------
    // GAS Effect Classes
    // ----------------------------------------

    /** Gameplay Effect that drains sanity in darkness (Infinite with Period) */
    UPROPERTY(EditDefaultsOnly, Category = "GAS|Sanity")
    TSubclassOf<UGameplayEffect> SanityDrainEffect;

    /** Gameplay Effect that regenerates sanity in light (Infinite with Period, capped) */
    UPROPERTY(EditDefaultsOnly, Category = "GAS|Sanity")
    TSubclassOf<UGameplayEffect> SanityRegenEffect;

private:
    // ----------------------------------------
    // Cached Light Actors
    // ----------------------------------------

    UPROPERTY()
    TArray<TWeakObjectPtr<AActor>> LightActors;

    // ----------------------------------------
    // State
    // ----------------------------------------

    bool bInLight = false;
    bool bInGracePeriod = false;

    // ----------------------------------------
    // Effect Handles
    // ----------------------------------------

    FActiveGameplayEffectHandle DrainHandle;
    FActiveGameplayEffectHandle RegenHandle;

    // ----------------------------------------
    // Timers
    // ----------------------------------------

    FTimerHandle LightCheckTimer;
    FTimerHandle GracePeriodTimer;

    // ----------------------------------------
    // Core Methods
    // ----------------------------------------

    /** Cache all protective light actors in the level */
    void CacheLightActors();

    /** Periodic check for light proximity */
    void CheckLightProximity();

    /** Called when player enters light zone */
    void OnEnterLight();

    /** Called when player exits light zone (starts grace period) */
    void OnExitLight();

    /** Called when grace period ends (starts drain) */
    void OnGracePeriodEnded();

    // ----------------------------------------
    // GAS Effect Management
    // ----------------------------------------

    void StartSanityDrain();
    void StopSanityDrain();
    void StartSanityRegen();
    void StopSanityRegen();

    /** Get the owning character's ASC */
    UAbilitySystemComponent* GetOwnerASC() const;

public:
    // ----------------------------------------
    // Public State Query
    // ----------------------------------------

    /** Returns true if player is currently in a protective light zone */
    UFUNCTION(BlueprintPure, Category = "Sanity|Light")
    bool IsInLight() const { return bInLight; }

    /** Returns true if player is in grace period (just left light) */
    UFUNCTION(BlueprintPure, Category = "Sanity|Light")
    bool IsInGracePeriod() const { return bInGracePeriod; }

    /** Force refresh of cached light actors (call on level load) */
    UFUNCTION(BlueprintCallable, Category = "Sanity|Light")
    void RefreshLightCache();
};
```

**Implementation (SanityPerceptionComponent.cpp):**

Key implementation details:
1. BeginPlay: CacheLightActors(), start LightCheckTimer at LightCheckInterval (looping)
2. EndPlay: Clear timers, stop any active effects
3. CacheLightActors:
   - Use UGameplayStatics::GetAllActorsOfClass for ALight::StaticClass()
   - Also get actors with ProtectiveLightTag (for windows/moonlight)
   - Filter OUT actors with FlickeringLightTag
   - Store in LightActors array

4. CheckLightProximity:
   - Get player location
   - For each cached light, check distance <= LightDetectionRadius
   - If any light in range and !bInLight: OnEnterLight()
   - If no lights in range and bInLight and !bInGracePeriod: OnExitLight()

5. OnEnterLight:
   - Set bInLight = true
   - Clear GracePeriodTimer if running
   - bInGracePeriod = false
   - StopSanityDrain()
   - StartSanityRegen()

6. OnExitLight:
   - Start GracePeriodTimer for GracePeriodDuration, callback OnGracePeriodEnded
   - bInGracePeriod = true
   - StopSanityRegen() // Stop regen immediately when leaving light

7. OnGracePeriodEnded:
   - bInGracePeriod = false
   - bInLight = false
   - StartSanityDrain()

8. Start/StopSanityDrain/Regen follow the HorrorCharacter pattern:
   - MakeEffectContext, MakeOutgoingSpec, ApplyGameplayEffectSpecToSelf
   - Store handle, check IsValid before apply
   - RemoveActiveGameplayEffect to stop

9. GetOwnerASC: Cast owner to IAbilitySystemInterface, call GetAbilitySystemComponent()

Include necessary headers:
- AbilitySystemComponent.h
- AbilitySystemInterface.h
- GameplayEffect.h
- Engine/PointLight.h
- Engine/SpotLight.h
- Kismet/GameplayStatics.h
